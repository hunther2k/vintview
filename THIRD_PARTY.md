# Third-party software

Vintview bundles the following open-source libraries (unmodified) in `app/src/main/assets/web/lib/`:

| Library | Version | License | Copyright |
|---|---|---|---|
| [pdf.js](https://github.com/mozilla/pdf.js) (`pdfjs-dist`, incl. cMaps and standard fonts) | 4.10.38 | Apache License 2.0 | Mozilla Foundation and contributors |
| [SheetJS Community Edition](https://sheetjs.com) (`xlsx`) | 0.20.3 | Apache License 2.0 | SheetJS LLC |

The full license texts are included next to the libraries
(`lib/pdfjs/LICENSE.txt`, `lib/xlsx/LICENSE.txt`) and inside every APK.

Android libraries: AndroidX Core and AndroidX WebKit (Apache License 2.0, The Android Open Source Project).
